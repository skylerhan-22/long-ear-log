# Long Ear Log（长耳日志）1.0 Demo

移动端优先的训练计时与饮食记录 PWA。产品使用纯黑白漫画界面和统一的兔子角色，重点是降低记录负担，不自动替用户制定训练或饮食计划。

完整的产品范围、交互规则、视觉规范、改动记录和验收标准见 [PRODUCT_V1.md](./PRODUCT_V1.md)。

## 1.0 功能

- 今日训练和饮食摘要
- 用户自定义七天训练计划
- 主动开始的训练计时器与逐组打卡
- 动态周训练目标
- 饮食照片、热量及可选三大营养素记录
- 饮食日、周、月回顾
- PWA 与基础离线缓存

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000/`。

## 验证

```bash
npm run build
node --test tests/*.test.mjs
```

## 1.0 边界

当前版本是前端 Demo：演示数据刷新后会重置；AI 热量识别只展示交互流程；账号、云同步、真实历史数据和生产级食物识别不属于 1.0。
